Privacy

Using the extension

Use the extension only with accounts and records you are authorized to edit. It prepares values in the existing Monthly Log form. Review hours, descriptions, existing entries and any partial changes before saving manually in Zoho. Stopping a run does not undo changes already entered. Changes to Zoho's interface may affect compatibility.
