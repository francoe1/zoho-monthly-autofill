Email: francoe12012@gmail.com

Before reporting a problem

Open Monthly Log in the active tab and select Project and Job. Use HH:MM duration mode. After updating the extension, review pending changes and reload Zoho.

What to include

Include the extension version, Chrome version, the error message, and reproduction steps. Remove private descriptions, project names and account details from screenshots. Never send passwords, tokens, cookies or unsanitized network exports.

Saving and errors

The extension does not save the Monthly Log automatically. If processing stops, review the indicated date and any partial changes before trying again.
