Get started

Install from the repository

You can install the current version manually from its source.

  1. Download the repository ZIP and extract it.
  2. Open chrome://extensions in Chrome and enable Developer mode.
  3. Choose Load unpacked and select the extracted src folder containing manifest.json.
  4. Open your Zoho Monthly Log in duration mode, select Project and Job, then open the extension.

Supports the expected Monthly Log form in the main page. Review your first run before saving. Stopping a run does not undo values already entered.
